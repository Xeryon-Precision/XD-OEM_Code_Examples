# C++ Examples — XD-OEM Motor Controller

This folder contains C++ examples for controlling an **XD-OEM motor controller**.

| Folder | Approach | Description |
|--------|----------|-------------|
| [`USB/`](USB/readme.md) | USB (library) | Cross-platform C++ SDK (CMake-based) for a USB/COM-connected setup, equivalent to the Python `Xeryon.py` API. |

> [!NOTE]
> See [`USB/readme.md`](USB/readme.md) for full setup, build, and usage details before running anything.

## Requirements

A C++ compiler (`g++`) on the target machine, plus CMake — see [`USB/readme.md`](USB/readme.md) for the specific compiler standard, libraries, and build commands.

> [!TIP]
> If you're looking for the same examples in Python, see [`../Python/readme.md`](../Python/readme.md).
