# EtherCAT Examples — XD-OEM Motor Controller

This folder contains EtherCAT resources for controlling an **XD-OEM motor controller**.

| Folder | Description |
|--------|-------------|
| [`Docs/`](Docs/) | EtherCAT command reference for the XD-OEM (`EtherCAT commands - Xeryon.pdf`). |
| [`TwinCAT/`](TwinCAT/readme.md) | A TwinCAT 3 project controlling one or more XD-OEM drives over EtherCAT — a reusable `XeryonDrive` function block, a 4-axis demo program, and a Python (ADS) scripting example. |

> [!NOTE]
> See [`TwinCAT/readme.md`](TwinCAT/readme.md) for full setup, wiring, and usage details before running anything.
