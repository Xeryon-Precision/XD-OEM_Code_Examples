# XD-OEM Motor Controller

This folder contains the manual and example code for the **XD-OEM motor controller**.

| Folder | Description |
|--------|-------------|
| [`Docs/`](Docs/) | The XD-OEM product manual (`Xeryon XD-OEM manual v3.3.pdf`). |
| [`Examples/`](Examples/readme.md) | Example code and projects for controlling the XD-OEM, organized by language/platform — Python, C++, EtherCAT, and LabVIEW. |

> [!TIP]
> Start with [`Docs/Xeryon XD-OEM manual v3.3.pdf`](<Docs/Xeryon XD-OEM manual v3.3.pdf>) for hardware setup and wiring, then see [`Examples/readme.md`](Examples/readme.md) to pick the language/platform matching your setup.
